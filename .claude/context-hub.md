# 上下文处理中心配置

## 🎯 核心功能
本配置启用统一的上下文管理和记忆系统，让AI助手能够智能地保存、检索和复用项目知识。

## 📦 自动记忆管理

### 触发条件 → 自动操作
| 触发条件 | 自动执行 | 存储位置 |
|---------|---------|---------|
| 子代理完成任务 | 提取核心内容 | Serena Memory |
| 代码修改>50行 | 记录修改模式 | 项目记忆 |
| 解决复杂问题 | 保存解决方案 | 长期记忆 |
| 发现新模式 | 更新知识库 | 知识库 |

## 🔄 工作流程

### 1. 新任务开始
```yaml
自动执行:
  - 查询相关记忆: mcp__serena__list_memories()
  - 读取类似经验: mcp__serena__read_memory()
  - 应用历史知识: 避免重复分析
```

### 2. 任务执行中
```yaml
持续监控:
  - 识别有价值内容: AI语义分析
  - 提取核心知识: 相关性>0.7
  - 建立关联: 链接相关记忆
```

### 3. 任务完成后
```yaml
自动保存:
  - 提取成功经验: mcp__serena__write_memory()
  - 更新知识图谱: 建立索引
  - 清理冗余: 合并相似记忆
```

## 💾 记忆分类规则

### 项目专属记忆
- **PDF解析模式**: `*-parser-patterns`
- **API设计方案**: `*-api-design`
- **Bug解决方案**: `*-fix-complete`
- **性能优化策略**: `*-optimization`

### 代码模式记忆
- **常用代码片段**: 自动识别重复使用的代码
- **错误处理模式**: 记录成功的错误处理策略
- **数据转换模式**: 保存验证过的转换逻辑
