# 服务商管理整合到卡车配送管理系统 - 设计文档

## 1. 设计概述

### 1.1 目标
将独立的服务商管理模块整合为卡车配送管理系统的子模块，形成更统一和层次化的管理体系。

### 1.2 设计原则
- **层次化结构**：服务商管理作为卡车配送的子功能
- **统一管理**：在卡车配送管理界面中统一管理所有相关功能
- **保持功能完整**：不损失现有服务商管理的任何功能
- **用户体验优化**：简化导航路径，提高操作效率

## 2. 信息架构调整

### 2.1 当前结构
```
管理中心
├── FSA管理
├── 卡车配送管理
│   ├── 城市管理
│   ├── 区域配置
│   └── 价格策略
└── 服务商管理（独立模块）
    ├── 服务商列表
    ├── 定价模型
    └── 服务区域
```

### 2.2 新结构
```
管理中心
├── FSA管理
└── 卡车配送管理（增强版）
    ├── 城市管理
    ├── 区域配置
    ├── 价格策略
    ├── 动态定价
    └── 服务商管理（子模块）
        ├── 服务商列表
        ├── 定价模型
        └── 服务区域
```
