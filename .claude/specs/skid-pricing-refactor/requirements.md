# 板数定价功能重构需求文档

## 项目概述

**项目名称**: 板数定价系统重构
**版本**: v2.0
**创建日期**: 2025-01-17
**状态**: 初始规划

## 当前问题分析

### 1. 界面布局问题
- **分散的定价模式**: 高级定价和固定定价分布在不同标签页，操作不够直观
- **复杂的选择逻辑**: 城市、分区、分组的选择逻辑过于复杂，在页面中不够集中
- **布局空间利用不当**: 组件占用空间不合理，影响整体使用体验

### 2. 功能限制
- **缺乏灵活性**: 不同定价模式之间切换困难
- **批量操作不便**: 无法高效地进行批量价格配置
- **价格策略单一**: 缺少阶梯定价等灵活的定价策略

## 核心需求

### 1. 层级选择器重构

#### 1.1 选择器布局
```
┌──────────────────────────────────────────────┐
│ 城市选择 (最大)                              │
│ [多伦多] [渥太华] [蒙特利尔] ...             │
└──────────────────────────────────────────────┘
           ↓
┌──────────────────────────────────────────────┐
│ 区域选择 (中等)                              │
│ [Downtown] [North York] [Scarborough] ...     │
└──────────────────────────────────────────────┘
           ↓
┌──────────────────────────────────────────────┐
│ 分组选择 (最小)                              │
│ [Group A] [Group B] [Group C] ...            │
└──────────────────────────────────────────────┘
```

#### 1.2 交互逻辑
- **城市级别**: 点击城市后，可直接对整个城市进行定价配置
- **区域级别**: 选择特定区域进行更细粒度的定价
- **分组级别**: 支持多选分组，实现最精细的定价控制

#### 1.3 价格优先级
```
分组价格 > 区域价格 > 城市价格
```
当同一个FSA同时具备多个层级的价格时，系统自动应用最高优先级的价格。

### 2. 定价模式整合

#### 2.1 四种定价模式

##### A. 固定价格模式
- **描述**: 每板固定单价
- **配置项**:
  - 单价（$/板）
- **适用场景**: 简单统一的定价策略

##### B. 首续托定价模式
- **描述**: 首托+续托差异化定价
- **配置项**:
  - 首托价格
  - 续托价格
  - 首托包含板数
- **适用场景**: 鼓励批量运输

##### C. 阶梯定价模式
- **描述**: 根据板数区间设置不同单价
- **配置项**:
  ```
  1-4板:   $X/板
  5-8板:   $Y/板
  9-12板:  $Z/板
  13-16板: $W/板
  16+板:   $V/板
  ```
- **适用场景**: 精细化的数量折扣策略

##### D. 整车定价模式
- **描述**: 达到特定板数后按整车计价
- **配置项**:
  - 整车起始板数
  - 整车价格
  - 低于整车板数的定价方式
- **适用场景**: 大批量运输优惠

#### 2.2 定价模式互斥规则
- 同一最小单元（城市/区域/分组）只能使用一种定价模式
- 不同最小单元可以使用不同的定价模式
- 切换定价模式时提示用户将清除当前配置

### 3. 用户界面设计

#### 3.1 整体布局
```
┌────────────────────────────────────────────────────┐
│                    顶部导航栏                       │
├────────────────────────────────────────────────────┤
│  城市选择条                                        │
├────────────────────────────────────────────────────┤
│  区域选择面板                                      │
├────────────────────────────────────────────────────┤
│  分组选择列表                                      │
├────────────────────────────────────────────────────┤
│                                                    │
│              定价配置面板                          │
│                                                    │
├────────────────────────────────────────────────────┤
│  操作按钮区 [保存] [重置] [导出]                   │
└────────────────────────────────────────────────────┘
```

#### 3.2 组件大小规范
- **城市选择器**: 高度 60px，突出显示
- **区域选择器**: 高度 45px，中等强调
- **分组选择器**: 高度 30px，紧凑布局
- **定价配置面板**: 保持当前大小

### 4. 功能特性

#### 4.1 批量操作
- 支持多选分组进行批量价格设置
- 提供"应用到所有"快捷操作
- 支持价格复制粘贴功能

#### 4.2 实时预览
- 选择不同层级时实时显示当前生效价格
- 价格冲突时显示优先级提示
- 提供价格计算器预览功能

#### 4.3 数据导入导出
- 支持Excel/CSV格式导入导出
- 保留历史价格版本
- 支持价格配置模板

## 技术要求

### 1. 性能要求
- 页面加载时间 < 2秒
- 价格计算响应时间 < 100ms
- 支持1000+分组的流畅操作

### 2. 兼容性要求
- 支持Chrome, Firefox, Safari最新版本
- 响应式设计，支持1366px以上分辨率
- 保持与现有API的兼容性

### 3. 数据结构

```typescript
interface PricingConfig {
  level: 'city' | 'zone' | 'group';
  targetId: string;
  mode: 'fixed' | 'progressive' | 'tiered' | 'truckload';
  config: ModeSpecificConfig;
  priority: number;
  effectiveDate?: Date;
}

interface TieredPricingConfig {
  tiers: Array<{
    minQty: number;
    maxQty: number;
    price: number;
  }>;
}
```
