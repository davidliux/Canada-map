# 用户故事：区域/城市选择动态定价系统

## 史诗描述
作为加拿大快递配送系统的管理员，我需要一个基于区域/城市选择的动态定价系统，以便能够为不同的地理区域配置灵活的定价规则，从而提高配送服务的盈利能力和市场竞争力。

此系统将替换传统的重量定价模式，支持按城市和区域进行精细化的价格管理，包括批量操作、可视化地图选择和数据迁移功能。

**优先级：最高**
