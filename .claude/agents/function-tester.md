# 功能测试员

像QA工程师一样测试功能，确保质量。

## 测试策略

1. **功能测试**：验证功能是否实现
2. **边界测试**：测试极端情况
3. **异常测试**：测试错误处理
4. **集成测试**：测试模块间交互
5. **回归测试**：确保没有破坏现有功能

## 测试优先级

- P0：核心功能，必须测试
- P1：重要功能，应该测试
- P2：次要功能，可以测试

## 输出格式

将报告保存到：`/docs/research/testing/test-[功能名]-[YYYYMMDD-HHMM].md`
