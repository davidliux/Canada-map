# Bug Verification Plan: 城市选择时所有城市颜色被覆盖

## Verification Steps

### Pre-Fix Verification
1. **记录当前错误行为**
   - [ ] 截图：未选中任何城市时的地图（显示多种颜色）
   - [ ] 截图：选中某个城市后的地图（所有城市变为同一颜色）
   - [ ] 记录受影响的城市和颜色变化

### Post-Fix Verification

#### 功能测试
1. **初始状态测试**
   - [ ] 加载页面，确认各城市显示不同的主题颜色
   - [ ] 检查每个城市的FSA区域颜色是否正确

2. **城市选择测试**
   - [ ] 选择AB城市（绿色），确认：
     - AB城市的FSA高亮显示
     - BC城市保持橙色
     - ON城市保持蓝色
     - 其他城市保持各自颜色

   - [ ] 选择BC城市（橙色），确认：
     - BC城市的FSA高亮显示
     - AB城市保持绿色
     - ON城市保持蓝色
     - 其他城市保持各自颜色

3. **城市切换测试**
   - [ ] 从AB城市切换到BC城市，颜色正确更新
   - [ ] 从BC城市切换到ON城市，颜色正确更新
   - [ ] 快速切换多个城市，确认没有颜色残留

4. **清除选择测试**
   - [ ] 点击清除按钮（×），恢复全局视图
   - [ ] 确认所有城市恢复到初始颜色状态

#### 交互测试
1. **FSA悬停测试**
   - [ ] 悬停在选中城市的FSA上，边框高亮正常
   - [ ] 悬停在其他城市的FSA上，边框高亮正常
   - [ ] 颜色保持不变，只有边框变化

2. **FSA点击测试**
   - [ ] 点击选中城市的FSA，弹窗显示正确信息
   - [ ] 点击其他城市的FSA，弹窗显示正确信息
   - [ ] 弹窗中的城市名称和颜色匹配

3. **区域筛选测试**
   - [ ] 选择城市后筛选特定区域
   - [ ] 确认只有该区域高亮，其他城市颜色不受影响

#### 性能测试
1. **渲染性能**
   - [ ] 地图加载时间合理（<2秒）
   - [ ] 城市切换响应迅速（<500ms）
   - [ ] 无明显卡顿或闪烁

2. **内存使用**
   - [ ] 多次切换城市后内存使用稳定
   - [ ] 无内存泄漏迹象

### 回归测试
1. **相关功能**
   - [ ] 搜索功能正常
   - [ ] 价格查询面板正常
   - [ ] 区域管理功能正常
   - [ ] 数据统计显示正确

2. **边缘情况**
   - [ ] 没有区域的城市显示正常
   - [ ] 只有一个FSA的区域显示正常
   - [ ] 空数据情况下不崩溃

## Expected Results
- ✅ 每个城市始终保持其独特的主题颜色
- ✅ 选中城市通过高亮效果区分，而不是改变其他城市颜色
- ✅ 用户可以清晰识别不同城市的配送区域
- ✅ 交互流畅，视觉反馈清晰

## Test Environment
- **浏览器**: Chrome, Firefox, Safari
- **分辨率**: 1920x1080, 1366x768
- **数据集**: 完整的加拿大FSA数据
