# Bug Report: 城市选择时所有城市颜色被覆盖

## Bug Summary
选中某个城市时，地图上所有城市的FSA区域都会变成当前选中城市的颜色，而不是保持各自的颜色。

## Environment
- **项目**: 加拿大快递配送区域地图系统
- **组件**: TruckDeliveryMap.jsx
- **页面**: /dashboards/truck-delivery

## Steps to Reproduce
1. 访问卡车派送数据大屏页面
2. 地图显示多个城市的FSA区域，每个城市有自己的主题色
3. 点击左侧城市列表中的任意城市（如AB城市）
4. 观察地图上所有城市的FSA区域颜色变化

## Expected Behavior
- 选中城市时，该城市的FSA区域应该高亮显示
- 其他未选中城市的FSA区域应该保持各自的主题颜色
- 每个城市应该始终保持其独特的视觉标识（颜色）

## Actual Behavior
- 选中某个城市后，地图上所有城市的FSA区域都变成了当前选中城市的颜色
- 失去了不同城市之间的视觉区分
- 影响用户对地图整体分布的理解

## Visual Evidence
- 用户提供的截图显示，选中AB城市（绿色）后，所有城市都变成了绿色
- 正常情况下应该有多种颜色代表不同城市

## Impact
- **严重性**: 中等
- **影响范围**: 视觉展示和用户体验
- **业务影响**: 难以区分不同城市的配送区域，影响运营决策

## Additional Context
- 系统设计中每个城市都有独特的theme_color属性
- 这是一个视觉渲染逻辑问题，不影响数据本身
