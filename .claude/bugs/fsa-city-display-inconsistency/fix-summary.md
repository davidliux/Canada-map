# Fix Summary: FSA点击弹窗城市显示不一致

## 修复内容
已成功修复FSA点击弹窗中城市信息显示不一致的问题。

### 修改文件
**src/components/TruckDeliveryMap.jsx**

### 具体修改

#### 1. 添加省份代码过滤（Lines 371-414）
- 定义了省份代码列表，用于识别和过滤省份代码
- 在查找城市名称时，检查并过滤掉省份代码
- 避免将省份代码（如MB、BC）显示为城市名

#### 2. 添加后备数据源（Lines 408-414）
```javascript
// 如果没有找到城市名称，或城市名称是省份代码，尝试从completeFSAData中获取
if (!cityName || provinceCodes.includes(cityName)) {
  const fsaInfo = completeFSAData.find(item => item.fsa === fsaCode);
  if (fsaInfo && fsaInfo.city) {
    cityName = fsaInfo.city;
  }
}
```

#### 3. 优化弹窗字段显示（Lines 437-472）
- 新增"所属省份"字段，始终显示省份信息
- "所属城市"字段只在有真正的城市名称时显示
- 将"城市区域"重命名为"FSA分组"，更准确地描述内容

### 字段调整
- **新增**："所属省份" - 显示FSA所属的省份代码
- **保留**："所属城市" - 只显示真正的城市名称
- **重命名**："城市区域" → "FSA分组"
- **保留**："配送区域" - 显示配送区域名称
- **保留**："FSA编码" - 显示FSA代码

## 问题原因
1. API返回的某些"城市"对象的name字段是省份代码而非城市名
2. 某些FSA未正确关联到城市数据
3. 字段命名不准确，造成理解混乱

## 解决方案
1. 过滤省份代码，避免将其显示为城市
2. 使用completeFSAData作为后备数据源
3. 优化字段名称和显示逻辑

- V2C FSA会显示"Kamloops"作为城市名
- 所有FSA都会正确显示省份信息
- 字段含义更加清晰准确
