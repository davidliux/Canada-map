# Bug Report: 1区颜色显示为灰色

## 问题描述
1区（Zone 1）在地图上的颜色显示为灰色，而其他区域（2区、3区、4区、5区）的颜色都正常显示。

## 重现步骤
1. 打开加拿大FSA真实边界地图应用
2. 进入快递筛选界面
3. 选择1区查看
4. 观察到1区的所有FSA区域显示为灰色，而不是应该显示的颜色

## 期望行为
1区应该显示与其他区域一样的正常颜色，通常每个区域都有其对应的特定颜色用于区分。

## 实际行为
- 1区的所有FSA区域显示为灰色
- 2区显示为绿色（正常）
- 3区、4区、5区都显示各自的颜色（正常）

## 影响范围
- 影响1区的视觉识别
- 可能影响用户对配送区域的理解
- 仅影响视觉显示，不影响功能

## 环境信息
- 浏览器：基于截图判断为现代浏览器
- 应用版本：最新开发版本
- 地图组件：Leaflet + React Leaflet

## 优先级
中等 - 影响用户体验但不影响核心功能

需要检查区域颜色配置和渲染逻辑，特别是1区的颜色设置。
