# Bug Report: 区域配置管理页面自动跳转问题

## 报告信息
- **报告时间**: 2024-09-17
- **报告者**: 用户
- **严重程度**: 高
- **状态**: 已分析

## 问题描述
在区域配置管理页面（/management/truck-delivery/regions）中，当用户对某个城市的区域进行增删改查操作后，页面会自动跳转到第一个城市（AB）的配置界面。

## 复现步骤
1. 打开区域配置管理页面
2. 选择任意非第一个城市（如ON、BC等）
3. 对该城市的区域进行任何操作（添加区域、编辑区域名称、删除区域等）
4. 操作完成后，页面自动跳转到AB城市的配置页面

## 预期行为
用户对某个城市的区域进行操作后，应该保持在当前城市的配置页面，而不是跳转到其他城市。

## 实际行为
页面自动跳转到城市列表的第一个城市（AB）。

## 影响
- 用户体验差，需要重新选择城市继续操作
- 存在数据安全风险：用户可能没有注意到页面跳转，误操作错误城市的数据

## 环境信息
- 页面路径: `/management/truck-delivery/regions`
- 受影响组件: `RegionsPage.jsx`
- 浏览器: 所有浏览器
