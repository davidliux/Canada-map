# 板数定价系统测试指南

## 🚀 快速开始

### 启动服务
1. **后端服务器** (端口 5050)
   ```bash
   cd backend
   npm start
   ```

2. **前端开发服务器** (端口 3001)
   ```bash
   npm run dev
   ```

## ⚠️ 常见问题

### 1. "Cannot read properties of undefined"
**原因**: API对象未正确导入
**解决**: 确保使用 `import truckDeliveryApi from ...`

### 2. 分组数据不显示
**原因**: 后端API未返回分组数据
**解决**:
- 检查数据库表 `truck_zone_fsa_groups` 是否有数据
- 验证API端点 `/zones/:zoneId/groups` 是否正常

### 3. 页面加载失败
**原因**: 服务器未启动或端口冲突
**解决**:
- 确保后端运行在5050端口
- 确保前端运行在3001端口
