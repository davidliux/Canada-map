# Logo 图片设置说明

## 如何添加您的 EIE Logo 图片

1. 将您的 logo 图片文件重命名为 `eie-logo.png`

2. 将图片文件放入 `public` 文件夹（当前文件夹）

3. 支持的图片格式：
   - PNG (推荐，支持透明背景)
   - JPG/JPEG
   - SVG

4. 如果使用其他格式，请相应修改 `src/components/Logo.jsx` 中的文件名

5. Logo 将自动显示在管理中心顶部导航栏

## 图片要求

- 推荐尺寸：宽度 200-400 像素
- 背景：透明背景效果最佳
- 文件大小：建议不超过 100KB

## 当前配置

Logo 组件支持三种尺寸：
- small: 120x48 像素
- default: 160x64 像素
- large: 200x80 像素

如果图片加载失败，将显示备用的文字 Logo。
