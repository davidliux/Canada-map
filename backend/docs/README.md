## 文档管理原则

1. 统一存放：所有文档放于 `backend/docs/` 下，分类清晰。
2. 命名规范：使用语义化文件名，含简要用途说明。
3. 质量评审：关键文档需进入 `quality-reviews` 评审流程并留痕。
4. 版本标注：文档头部标注版本与更新时间。
5. 链接复用：可通过相对链接引用项目根部已有文档。
